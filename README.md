## Descripción

Beauty Skin es una maquetación visual y responsiva de la página principal de una tienda online de maquillaje y productos para el cuidado de la piel.

Para esta tarea se estuvo utilizando HTML, CSS y Bootstrap 5. La página es únicamente una demostración visual, por lo que los botones y las categorías no poseen funcionalidad.

## Componentes utilizados

- Carousel de Bootstrap.
- Sistema Grid responsivo.
- Clases `container`, `row`, `col-sm-3` y `col-sm-9`.
- Cards para mostrar productos.
- List Group para el menú de categorías.
- Botones de Bootstrap.
- Bootstrap Icons.
- Badge para el contador del carrito.
- Footer personalizado.
- Media queries para mejorar la presentación en dispositivos pequeños.

## Diseño responsivo

En pantallas medianas y grandes se muestran tres productos por fila.

En pantallas pequeñas, los productos ocupan el 100% del ancho y se muestran uno debajo del otro.
